# Khaled ALHariri — IT Manager Resume

Interactive cyberpunk-themed resume built with pure HTML/CSS.

## 🔗 Live Preview

👉 [View Resume](https://khaled-alhariri.github.io/resume/)

> Replace `yourusername` with your actual GitHub username.

## Features

- Dark cyberpunk theme with blue/cyan accents
- Animated photo frame with scan-line effect
- Interactive skill progress bars
- Hover effects on stat cards and tech stack
- Fully responsive (mobile + desktop)
- Print-ready (`Ctrl+P` preserves dark background)

## Deployment

This site is deployed via **GitHub Pages** from the `main` branch.

## Tech

- HTML5 + CSS3 (no frameworks)
- Google Fonts: Orbitron, Rajdhani, Share Tech Mono
- Photo embedded as base64 (no external dependencies)
